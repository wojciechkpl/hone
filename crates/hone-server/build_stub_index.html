Hone web UI is not bundled in this honed binary.

The SolidJS app source lives at apps/webui/. To build and embed it: 

make webui
cargo build --release -p honed

For dev iteration you can also run the SolidJS app directly with hot reload — it proxies API + SSE requests to a locally-running honed: 

make webui-dev
# then open http://127.0.0.1:5174

The TUI and CLI work without this build step; hone and hone tui are unaffected.
